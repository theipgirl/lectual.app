## From Ketrone: what's worth using

Ketrone (Abu Dhabi, UAE/KSA law, $1,488-$4,752 per user per year) is a matter-centric AI workspace. Most of it Lectual already has (boards,
approvals, drafting from the firm's templates, Outlook sync). The ideas that answer things from this call:

| Ketrone idea | Use in Lectual | Call item it answers |
|---|---|---|
| Matter Engine: email + docs create and update matters | Suggest a new matter when a client's mail or consult notes ask for new work; staff confirm a pre-filled form | Adding work for an existing client |
| Client workspaces | A client page listing every lead, matter, proposal and file across Trademarks, Contracts, GC | Kylie: all her matters in one view |
| Vault: "files stay where they are", linked to the matter | Link SharePoint / OneDrive / Drive files to a card instead of copying | File organization, Lawmatics folder mess |
| Skills in plain language, with routing + an SLA (e.g. NDA prescreen, red/yellow/green, to a named lawyer in 4 h) | A "redline intake" skill: client submits redline + request + clean copy; triaged and routed with a due time | Kylie / Brittany redlines |
| Conflict check skill (parties vs open and closed matters) | Run on intake and on a new matter | Good hygiene as matters grow |
| Every view logged, information barriers | Later; Lectual already logs approvals | Not urgent |

Not worth copying: Arabic / UAE law research, their self-reported benchmarks, Word add-in (later, if redlines grow).
