-- -- VIEW LAYOUTS ----------------------------------------------------------------------------------------------------
--   view_key in: review_list_trademarks, review_list_contracts, review_board, matters_list, matters_board, contracts_list, contracts_board, leads_list, leads_board.
--   columns: a jsonb ARRAY of 1..80 objects, keys exactly from {key, label, hidden, width}:
--     key     required. A built-in column key, ^[a-z][a-z0-9_]{0,39}$ (the app's fixed keys; the database does not know which keys a
--             view has: an unknown built-in key is the app's to ignore), or `cf:<uuid>` naming one of THIS firm's crm_custom_field rows
--             (archived allowed; the trigger refuses another firm's or a missing id, view_layout_unknown_field, 23503). Keys distinct.
--     label   optional. null or absent = the column's own name; else 1..60 characters, with no leading or trailing Unicode whitespace
--             (space, tab, line breaks, U+00A0, U+1680, U+2000-200A, U+2028/2029, U+202F, U+205F, U+3000, U+FEFF), no C1 or C0
--             control (U+0000-001F, U+007F-009F, written out) and no invisible direction mark. A rename is the
--             label only: data, filters and rules keep reading the key.
--     hidden  required boolean.
--     width   optional. null or absent = default; else a whole number of pixels 40..800.
--   rev: 1 on insert, +1 on every update (trigger). The app writes with `.eq("rev", <rev it drew>)` so a second owner's stale form
--   updates 0 rows instead of silently overwriting (the consult-details `rev` pattern). A missing row = the app's default layout; a
--   failed read draws the default with one note (three states, never "no columns"). Delete = "reset to default" (owner).
--   Grants: authenticated SELECT, DELETE, INSERT (org_id, view_key, columns), UPDATE (columns). rev, updated_by, updated_at,
--   created_at and id have no write grant: the trigger stamps them (updated_by = auth.uid(), null = the system, as 0085).

-- -- STAGE ROLES -----------------------------------------------------------------------------------------------------
-- A role is a fixed tag a RULE reads instead of a stage's name, so a rename or reorder changes nothing a rule does. Every role below
-- exists because a rule in lectual.app finds a stage by NAME today (file named). Roles are never typed in the UI.
--
-- THE BACK-FILL PRINCIPLE: a role is written on stage S only where EVERY rule that will read the role ALREADY picks S today, and at
-- least one of them picks it by NAME (never from position alone). So on the day this is applied, "role first, else today's name rule"
-- gives every rule exactly today's answer. Where the readers disagree, where one finds nothing, or where a candidate name matches two
-- stages (today's code would take whichever came first: that is a guess), the role stays NULL and the rules keep their name match. A
-- stage picked for two roles gets neither. Firm brain `stage_mapping` entries (crm firm brain, content) are NOT read: the app keeps
-- reading a brain entry FIRST (the firm said what it meant), then the role, then the default names.
-- Name keys mirror the app exactly: crm_stage_name_key = lectual.app normalizeStageName (src/lib/lawmatics/stage-map.ts: lowercase,
-- strip a leading "4." / "4)" / "4 -" / "4:", "&" -> " and ", every other non [a-z0-9] run -> one space, trim). "resolve" = that
-- file's resolveStage: the candidate's key against the stages' keys, then the candidate key's ALIASES entry (copied verbatim below),
-- candidates tried in order, first hit wins.

-- -- STAGE FUNCTIONS: SHARED RULES -----------------------------------------------------------------------------------
--   * Caller: an OWNER MEMBERSHIP ROW (crm_org_member: org_id = current_org_id(), user_id = auth.uid(), role = 'owner'). Never the
--     claim, so a platform admin (0050) inside a firm is refused like a paralegal (stage_not_owner). No session = stage_not_owner.
--   * The firm is always current_org_id(); there is no org argument. A stage id of another firm reads exactly like a missing one
--     (stage_not_found / stage_delete_bad_destination, 42501), so a function is no oracle about other firms.
--   * Positions are 0-based places in the firm's order (order_index, then name, then id: lectual.app compareStageOrder). Every change
--     renumbers the WHOLE firm list in steps of 10 in two phases (both tables have a non-deferrable unique (org_id, order_index)):
--     phase 1 moves every row above max(existing max, 10 x count) + 1, phase 2 writes (place x 10). At most 200 stages per firm per
--     table (stage_limit); an order_index past 1,000,000,000 is stage_order_overflow (also checked before an add's max + 1), so a
--     lead stage's order_index stays far below the Weekly review's MATTER_ORDER_BASE (100000) in practice.
--   * Locking: a per-firm advisory lock ('crm_stage:' or 'crm_matter_stage:' || org id) serializes the functions. Only the stage being
--     changed is locked FOR UPDATE (and, on delete, the records in it); the firm's other stage rows are NOT row-locked up front, so
--     ordinary lead writes (which take the FK's KEY SHARE on their stage) are not blocked by a rename or an add. A renumber's UPDATE
--     does take each row's lock for the moment it runs. The app answers 40P01 (deadlock) and 55P03 with a fixed sentence and ONE
--     retry.
--   * Names: trimmed, 1..80 characters (lead) / 1..200 (matter, 0042's CHECK), no control characters, no invisible direction or
--     zero-width marks (U+200B-U+200F, U+202A-U+202E, U+2066-U+2069), and a key that is not empty (stage_bad_name). A new or renamed
--     stage may not share its key with another stage of the firm (stage_name_taken, 23505): two stages with one key are exactly what
--     makes today's name rules guess. Existing duplicates are left alone.
--   * Matter stage codes are generated at add (the label's ASCII letters and digits, uppercased, at most 12, an "S" prefix when it
--     would start with a digit so it never looks like a tracker code, then "-2", "-3" ... on a collision; "STAGE" when nothing is
--     left) and NEVER change (stage_code_fixed for a signed-in caller; no function changes it).
--   * Moves write crm_activity `stage_changed` rows shaped like the app's own (src/lib/pipeline/leads.ts moveLeadStage for leads:
--     from_stage, to_stage, from_stage_id, to_stage_id; src/lib/matters/stages.ts updateMatterStage for matters: from_code,
--     from_label, to_code, to_label, plus from_stage_id / to_stage_id), actor_type user, actor_id auth.uid(), plus
--     reason 'stage deleted' and stage_deleted true. last_activity_at is NOT touched (lists sort on it; the cleanup script's rule).
--
-- -- DELETE WITH MOVE ------------------------------------------------------------------------------------------------
--   In ONE transaction: lock the stage, lock every record in it, compare the SET of live record ids (leads: merged_into_id is null;
--   matters: all, any status) with p_expected_ids (exactly the records the dialog showed; an empty stage takes '{}'). Any difference,
--   in count or in which records, is stage_delete_records_changed and nothing is written: a count alone cannot see one lead moving
--   out while another moves in. Then the refusals, the moves (leads: current_stage_id + stage_entered_at = now(); matters: stage_id +
--   stage_entered_at + updated_at = now()), one stage_changed row per moved live record, the role, and the delete. An empty stage
--   needs no destination (one given is ignored). Order of checks: ids, role, last open, last won, destination.
--   Destination: required when the stage holds anything; not the stage itself; this firm's.
--     Leads: a won destination only FROM a won stage (stage_delete_won_destination otherwise: a person's move into won runs the
--     matter handoff); and from a won stage ONLY a won destination (stage_delete_won_source: those leads already had their handoff and
--     must not go back to open, lost or nurture). So the last won stage can be deleted only while it holds no lead.
--     Matters: any other matter stage of the firm with the SAME is_open (stage_delete_open_mismatch), unless
--     p_confirm_open_change is true: a delete must not silently reopen or close matters.
--   Role holder: p_role_to names another stage of the firm, holding no role, that the role's category / open rule allows; or
--     p_role_to null DROPS the role (the rules fall back to today's name match, safer than forcing the role onto some other stage),
--     for every role EXCEPT new_enquiry (always needs p_role_to) and signed_loe (lead: needs p_role_to, unless it is the firm's last
--     won stage and p_confirm_no_won is true; matter: always needs p_role_to): stage_holds_role.
--   The result: deleted, destination, moved, moved_ids (the live records moved), merged_moved (leads), role_moved_to, role_dropped,
--   and rules_naming_stage (leads): how many automation rules (crm_automation_rule, 0022) mention the stage id in their config,
--   conditions or actions. A deleted stage id in a rule's change_stage action makes that action fail (23503), never move anyone.
--   Nothing here edits a rule. History: earlier stage_changed rows keep the stage's id and name, so timelines still read.
--   WHAT THE APP MUST DO AFTER A DELETE (the SQL does not do it): a person's move in lectual.app also stops sequences
--   (stopLeadSequencesAsStaff, for a won destination) and runs `stage_changed` automation rules (runRules). A stage delete does
--   neither in SQL: enrolments are app state with their own rules (0085), and rules run in the app. After a successful delete the
--   app runs, for every id in moved_ids, the same sequence-stop handling a person's move to that destination would run, and decides
--   explicitly whether stage_changed rules fire (recommended: not, since nobody chose a new stage for these leads). The Working
--   rule and any reader that counts "a person moved this lead" must skip rows whose payload has stage_deleted = true.
--
-- -- MERGED LEADS (0107) ---------------------------------------------------------------------------------------------
--   A merged lead keeps its current_stage_id forever and 0107's guard refuses ANY update of it, so a stage holding a merged
--   duplicate could never be deleted (the FK is NO ACTION) and an owner would be blocked by a record the app does not even show.
--   Rule chosen: merged leads do not block and are not in p_expected_ids. crm_stage_delete moves them to the destination with
--   current_stage_id ONLY (no stage_entered_at, no timeline row: a merged lead's timeline is read through its keeper, and a "moved by
--   stage delete" line there would read as a move of the keeper); the result reports them (`merged_moved`). A stage holding only
--   merged leads still needs a destination. A stage holding only merged leads can never change category (stage_not_empty counts
--   them, and the app does not show them): delete it with a destination instead.
--   How: the replaced guard lets exactly this through: an UPDATE of a merged row where current_user is the owner of
--   public.crm_stage_delete(uuid,uuid,uuid[],uuid,boolean) (a SECURITY DEFINER function runs as its owner; API callers are
--   authenticated / anon / service_role and cannot SET ROLE), the transaction-local `lectual.stage_delete` equals
--   '<old.current_stage_id>><new.current_stage_id>' (set by crm_stage_delete just before, cleared just after), and nothing but
--   current_stage_id differs (to_jsonb(new) - 'current_stage_id' = to_jsonb(old) - 'current_stage_id'). Every 0107 behaviour is
--   unchanged. Same limit as 0107: a session running AS the function owner (postgres: dashboard SQL, migrations) can set the marker,
--   and so could any OTHER postgres-owned SECURITY DEFINER function that calls set_config('lectual....', <caller's argument>):
--   PRE-APPLY CHECK 9 looks for one.
--   Not chosen: refusing the delete (an owner blocked by an invisible row); moving them to the keeper's stage (each merged lead would
--   land somewhere different, and the keeper's stage might be the one being deleted); a soft-deleted "archived" stage (every stage
--   read in both apps would have to learn to hide it).

returns text
language sql
immutable
set search_path = ''
as $$
  select pg_catalog.btrim(

      pg_catalog.replace(

$$;

-- One layout column. Pure; CASE chains so nothing is cast or expanded before its type is known.
create or replace function public.crm_view_layout_column_valid(p jsonb)
returns boolean
language plpgsql
immutable
set search_path = ''
as $$
declare
  -- Built with chr() so this body is pure ASCII and survives any transport (dev's first copy had its escapes turned into literal
  -- invisible characters in transit). Space-like: tab, LF, CR, FF, VT, U+00A0, U+1680, U+2000-200A, U+2028, U+2029, U+202F, U+205F,
  -- U+3000, U+FEFF. Controls: U+0001-001F, U+007F-009F. Invisible marks: U+200B-200F, U+202A-202E, U+2066-2069.
  v_space text := '[ ' || pg_catalog.chr(9) || pg_catalog.chr(10) || pg_catalog.chr(13) || pg_catalog.chr(12) || pg_catalog.chr(11)
                  || pg_catalog.chr(160) || pg_catalog.chr(5760) || pg_catalog.chr(8192) || '-' || pg_catalog.chr(8202)
                  || pg_catalog.chr(8232) || pg_catalog.chr(8233) || pg_catalog.chr(8239) || pg_catalog.chr(8287)
                  || pg_catalog.chr(12288) || pg_catalog.chr(65279) || ']';
  v_ctl   text := '[' || pg_catalog.chr(1) || '-' || pg_catalog.chr(31) || pg_catalog.chr(127) || '-' || pg_catalog.chr(159) || ']';
  v_inv   text := '[' || pg_catalog.chr(8203) || '-' || pg_catalog.chr(8207) || pg_catalog.chr(8234) || '-' || pg_catalog.chr(8238)
                  || pg_catalog.chr(8294) || '-' || pg_catalog.chr(8297) || ']';
begin
  if pg_catalog.jsonb_typeof(p) is distinct from 'object' then return false; end if;
  if exists (select 1 from pg_catalog.jsonb_object_keys(p) k where k not in ('key', 'label', 'hidden', 'width')) then return false; end if;
  if pg_catalog.jsonb_typeof(p -> 'key') is distinct from 'string' then return false; end if;
  if not ((p ->> 'key') ~ '^[a-z][a-z0-9_]{0,39}$'
          or (p ->> 'key') ~ '^cf:[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$') then
    return false;
  end if;
  if pg_catalog.jsonb_typeof(p -> 'hidden') is distinct from 'boolean' then return false; end if;
  if p ? 'label' and pg_catalog.jsonb_typeof(p -> 'label') <> 'null' then
    if pg_catalog.jsonb_typeof(p -> 'label') <> 'string'
       or pg_catalog.char_length(p ->> 'label') not between 1 and 60
       -- Revised after the step 2 review: the rule is written out character by character, never through the locale-dependent POSIX classes
       -- (control and space), so the app's parseLayout (src/lib/views/layout/validate.ts) and this CHECK accept exactly the same labels.
       or (p ->> 'label') ~ ('^' || v_space)
       or (p ->> 'label') ~ (v_space || '$')
       or (p ->> 'label') ~ v_ctl
       or (p ->> 'label') ~ v_inv then
      return false;
    end if;
  end if;
  if p ? 'width' and pg_catalog.jsonb_typeof(p -> 'width') <> 'null' then
    if pg_catalog.jsonb_typeof(p -> 'width') <> 'number' or (p ->> 'width') !~ '^[0-9]{1,4}$' then return false; end if;
    if (p ->> 'width')::int not between 40 and 800 then return false; end if;
  end if;
  return true;
end
$$;

create or replace function public.crm_view_layout_columns_valid(p jsonb)
returns boolean
language plpgsql
immutable
set search_path = ''
as $$
begin
  if pg_catalog.jsonb_typeof(p) is distinct from 'array' then return false; end if;
  if pg_catalog.jsonb_array_length(p) not between 1 and 80 then return false; end if;
  if exists (select 1 from pg_catalog.jsonb_array_elements(p) e(v) where not public.crm_view_layout_column_valid(e.v)) then
    return false;
  end if;
  return (select pg_catalog.count(distinct e.v ->> 'key') from pg_catalog.jsonb_array_elements(p) e(v))
         = pg_catalog.jsonb_array_length(p);
end
$$;

create table if not exists public.crm_view_layout (
  id          uuid        primary key default gen_random_uuid(),
  org_id      uuid        not null references public.crm_org(id) on delete cascade,
  view_key    text        not null,
  columns     jsonb       not null,
  rev         int         not null default 1,
  -- No write grant: the trigger stamps auth.uid() (null = the system, 0085).
  updated_by  uuid        default auth.uid() references auth.users(id) on delete set null,
  updated_at  timestamptz not null default now(),
  created_at  timestamptz not null default now(),
  constraint crm_view_layout_view_key check (view_key in (
    'review_list_trademarks', 'review_list_contracts', 'review_board', 'matters_list', 'matters_board',
    'contracts_list', 'contracts_board', 'leads_list', 'leads_board')),
  constraint crm_view_layout_columns check (public.crm_view_layout_columns_valid(columns)),
  constraint crm_view_layout_rev check (rev >= 1),
  constraint crm_view_layout_one_per_view unique (org_id, view_key)
);
-- For the auth.users ON DELETE SET NULL on updated_by (as 0106 / 0115 do).
create index if not exists crm_view_layout_updated_by_idx on public.crm_view_layout (updated_by);

create or replace function public.crm_view_layout_rules()
returns trigger
language plpgsql
set search_path = ''
as $$
declare
  v_key text;
  v_ok boolean;
begin
  -- 1. The FK's own ON DELETE SET NULL of updated_by: let exactly that through (0106 / 0115 form), no stamp.
  if tg_op = 'UPDATE' and pg_trigger_depth() > 1
     and (to_jsonb(new) - 'updated_by') = (to_jsonb(old) - 'updated_by') and new.updated_by is null then
    return new;
  end if;

  -- 2. Immutable, for every caller including the service role (signed-in callers are stopped earlier by the grants: 42501).
  if tg_op = 'UPDATE' and (new.id is distinct from old.id or new.org_id is distinct from old.org_id
                           or new.view_key is distinct from old.view_key or new.created_at is distinct from old.created_at) then
    raise exception 'view_layout_immutable: a layout''s firm and view never change' using errcode = '23514';
  end if;

  -- 3. A firm column named in the layout must be one of THIS firm's (archived allowed). Another firm's id reads as missing.
  --    A BEFORE trigger runs before the CHECK, so a malformed list is left for crm_view_layout_columns to refuse (no cast here).
  if not public.crm_view_layout_columns_valid(new.columns) then
    return new;
  end if;
  for v_key in select e.v ->> 'key' from pg_catalog.jsonb_array_elements(new.columns) e(v) where (e.v ->> 'key') like 'cf:%' loop
    if pg_catalog.to_regclass('public.crm_custom_field') is null then
      v_ok := false;
    else
      execute 'select exists (select 1 from public.crm_custom_field f where f.id = $1 and f.org_id = $2)'
        into v_ok using pg_catalog.substr(v_key, 4)::uuid, new.org_id;
    end if;
    if not v_ok then
      raise exception 'view_layout_unknown_field: the layout names a column this firm does not have' using errcode = '23503';
    end if;
  end loop;

  -- 4. Stamps, overwriting what was sent.
  if tg_op = 'INSERT' then
    new.rev := 1;
    new.created_at := now();
  else
    new.rev := old.rev + 1;
  end if;
  new.updated_by := auth.uid();
  new.updated_at := now();
  return new;
end
$$;
revoke all on function public.crm_view_layout_rules() from public, anon, authenticated;

do $$
begin
  if not exists (select 1 from pg_trigger where tgname = 'crm_view_layout_rules_trg'
                 and tgrelid = 'public.crm_view_layout'::regclass) then
    create trigger crm_view_layout_rules_trg
      before insert or update on public.crm_view_layout
      for each row execute function public.crm_view_layout_rules();
  end if;
end
$$;

-- -- 4. Role and structure triggers ----------------------------------------------------------------------------------
-- Roles: signed-in callers cannot write `role` (stage_role_guarded); every caller obeys the role / category (lead) and role / open
-- (matter) pairings and "a role holder is not deleted" (clear, drop or move the role first; the delete functions do).
-- Structure (WHAT IT CHANGES 2): a signed-in caller without an owner membership row cannot change a structural column
-- (stage_owner_only); nobody signed in changes a matter stage's code (stage_code_fixed) or a stage's category / is_open while it holds
-- a record (stage_not_empty). Insert and delete by a signed-in non-owner are refused by the restrictive policies in part 7.
-- `authenticated` / `anon` are the only roles judged here: the service role and the SECURITY DEFINER functions (table owner) pass.
create or replace function public.crm_stage_is_owner_row(p_org uuid)
returns boolean
language sql
stable
set search_path = ''
as $$
  select exists (select 1 from public.crm_org_member m
                  where m.org_id = p_org and m.org_id = public.current_org_id() and m.user_id = auth.uid() and m.role = 'owner')
$$;

create or replace function public.crm_stage_role_rules()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  if tg_op = 'DELETE' then
    -- A firm's own deletion cascades from crm_org (nested); a direct delete of a role holder is refused for everyone.
    if old.role is not null and pg_trigger_depth() <= 1 then
      raise exception 'stage_role_delete: this stage holds a role; give the role to another stage first' using errcode = '23514';
    end if;
    return old;
  end if;
  if (tg_op = 'INSERT' and new.role is not null) or (tg_op = 'UPDATE' and new.role is distinct from old.role) then
    if current_user in ('authenticated', 'anon') then
      raise exception 'stage_role_guarded: a stage''s role is set by Lectual' using errcode = '42501';
    end if;
  end if;
  if tg_op = 'UPDATE' and current_user in ('authenticated', 'anon') then
    if (new.name is distinct from old.name or new.order_index is distinct from old.order_index
        or new.category is distinct from old.category or new.org_id is distinct from old.org_id)
       and not public.crm_stage_is_owner_row(old.org_id) then
      raise exception 'stage_owner_only: only an owner of this firm can change its stages' using errcode = '42501';
    end if;
    if new.category is distinct from old.category
       and exists (select 1 from public.crm_lead l where l.current_stage_id = old.id and l.org_id = old.org_id) then
      raise exception 'stage_not_empty: move this stage''s leads first' using errcode = '23514';
    end if;
  end if;
  if new.role is not null and not (
       (new.role in ('new_enquiry', 'follow_up') and new.category = 'open')
    or (new.role = 'signed_loe' and new.category = 'won')
    or (new.role = 'lost' and new.category = 'lost')
    or new.role not in ('new_enquiry', 'follow_up', 'signed_loe', 'lost')) then
    raise exception 'stage_role_category_mismatch: this role cannot sit on a stage of that category' using errcode = '23514';
  end if;
  return new;
end
$$;

create or replace function public.crm_matter_stage_role_rules()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  if tg_op = 'DELETE' then
    if old.role is not null and pg_trigger_depth() <= 1 then
      raise exception 'stage_role_delete: this stage holds a role; give the role to another stage first' using errcode = '23514';
    end if;
    return old;
  end if;
  if (tg_op = 'INSERT' and new.role is not null) or (tg_op = 'UPDATE' and new.role is distinct from old.role) then
    if current_user in ('authenticated', 'anon') then
      raise exception 'stage_role_guarded: a stage''s role is set by Lectual' using errcode = '42501';
    end if;
  end if;
  if tg_op = 'UPDATE' and current_user in ('authenticated', 'anon') then
    if new.code is distinct from old.code then
      raise exception 'stage_code_fixed: a stage''s code never changes' using errcode = '42501';
    end if;
    if (new.label is distinct from old.label or new.order_index is distinct from old.order_index
        or new.is_open is distinct from old.is_open or new.org_id is distinct from old.org_id)
       and not public.crm_stage_is_owner_row(old.org_id) then
      raise exception 'stage_owner_only: only an owner of this firm can change its stages' using errcode = '42501';
    end if;
    if new.is_open is distinct from old.is_open
       and exists (select 1 from public.crm_matter m where m.stage_id = old.id and m.org_id = old.org_id) then
      raise exception 'stage_not_empty: move this stage''s matters first' using errcode = '23514';
    end if;
  end if;
  if new.role is not null and not (
       (new.role in ('signed_loe', 'application_filed', 'oa_issued', 'awaiting_registration', 'publication') and new.is_open)
    or (new.role in ('registered', 'abandoned') and not new.is_open)) then
    raise exception 'stage_role_category_mismatch: this role cannot sit on an open (or closed) stage' using errcode = '23514';
  end if;
  return new;
end
$$;

revoke all on function public.crm_stage_role_rules() from public, anon, authenticated;
revoke all on function public.crm_matter_stage_role_rules() from public, anon, authenticated;

-- -- 5. crm_lead_merge_guard: 0107's body verbatim, plus the stage-delete branch (marked 0119) ------------------------
create or replace function public.crm_lead_merge_guard()
returns trigger
language plpgsql
set search_path = ''
as $$
declare
  v_owner text;
  v_row   uuid;
  v_move  text;                               -- 0119
begin
  -- Referential actions (FK SET NULL / cascade) arrive nested.
  if pg_trigger_depth() > 1 then
    if tg_op = 'DELETE' then
      return old;
    end if;
    return new;
  end if;

  if tg_op = 'INSERT' then
    if new.merged_into_id is not null or new.merged_at is not null or new.merged_by is not null then
      raise exception 'lead_merge_guarded: a lead is merged only by crm_merge_leads'
        using errcode = '42501';
    end if;
    return new;
  end if;

  if tg_op = 'UPDATE'
     and old.merged_into_id is null
     and new.merged_into_id is null
     and new.merged_at is not distinct from old.merged_at
     and new.merged_by is not distinct from old.merged_by then
    return new;                               -- an ordinary update of a live lead
  end if;

  if tg_op = 'DELETE' and old.merged_into_id is null then
    return old;                               -- deleting a live lead: RLS decides
  end if;

  -- 0119: inside crm_stage_delete only, a merged lead parked in the stage being deleted moves to the destination, and nothing
  -- else about it changes.
  if tg_op = 'UPDATE' and old.merged_into_id is not null then
    select r.rolname into v_owner
      from pg_catalog.pg_proc p
      join pg_catalog.pg_roles r on r.oid = p.proowner
     where p.oid = to_regprocedure('public.crm_stage_delete(uuid,uuid,uuid[],uuid,boolean)');
    v_move := nullif(current_setting('lectual.stage_delete', true), '');
    if v_owner is not null
       and current_user = v_owner
       and v_move = old.current_stage_id::text || '>' || new.current_stage_id::text
       and (to_jsonb(new) - 'current_stage_id') = (to_jsonb(old) - 'current_stage_id') then
      return new;
    end if;
  end if;

  -- Only inside crm_merge_leads, and only for the row it is marking.
  select r.rolname into v_owner
    from pg_catalog.pg_proc p
    join pg_catalog.pg_roles r on r.oid = p.proowner
   where p.oid = to_regprocedure('public.crm_merge_leads(uuid,uuid,jsonb)');
  v_row := nullif(current_setting('lectual.lead_merge', true), '')::uuid;

  if tg_op = 'UPDATE'
     and v_owner is not null
     and current_user = v_owner
     and v_row = old.id
     and old.merged_into_id is null then
    return new;
  end if;

  if tg_op = 'DELETE' then
    raise exception 'lead_merge_guarded: a merged lead cannot be deleted; its history is shown on the lead it was merged into'
      using errcode = '42501';
  end if;
  if old.merged_into_id is not null then
    raise exception 'lead_merge_guarded: this lead was merged into another lead and cannot be changed'
      using errcode = '42501';
  end if;
  raise exception 'lead_merge_guarded: a lead is merged only by crm_merge_leads'
    using errcode = '42501';
end
$$;
revoke all on function public.crm_lead_merge_guard() from public, anon, authenticated;
-- The trigger itself (0107: crm_lead_merge_guard, before insert or update or delete) is unchanged and not re-created.

create or replace function public.crm_stage_clean_name(p_name text, p_max int)
returns text
language plpgsql
immutable
set search_path = ''
as $$
declare
  v text := pg_catalog.btrim(coalesce(p_name, ''));
  -- U+200B-200F, U+202A-202E, U+2066-2069, built with chr() so this body is pure ASCII.
  v_inv text := '[' || pg_catalog.chr(8203) || '-' || pg_catalog.chr(8207) || pg_catalog.chr(8234) || '-' || pg_catalog.chr(8238)
                || pg_catalog.chr(8294) || '-' || pg_catalog.chr(8297) || ']';
begin
  if pg_catalog.char_length(v) not between 1 and p_max or v ~ '[[:cntrl:]]'
     or v ~ v_inv then
    raise exception 'stage_bad_name: a stage name is 1 to % characters with no control or invisible characters', p_max using errcode = '22023';
  end if;
  return v;
end
$$;

-- Two-phase renumber of a firm's LEAD stages to the order given (every stage of the firm, each once).
create or replace function public.crm_stage_renumber(p_org uuid, p_ids uuid[])
returns void
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_base bigint;
  v_n int;
begin
  select pg_catalog.count(*) into v_n from public.crm_stage where org_id = p_org;
  if v_n <> pg_catalog.cardinality(p_ids)
     or v_n <> (select pg_catalog.count(distinct x) from pg_catalog.unnest(p_ids) x)
     or exists (select 1 from pg_catalog.unnest(p_ids) x where not exists (
                  select 1 from public.crm_stage s where s.id = x and s.org_id = p_org)) then
    raise exception 'stage_bad_position: the new order must name every stage of the firm once' using errcode = '22023';
  end if;
  select greatest(coalesce(max(order_index), 0)::bigint, v_n::bigint * 10) + 1 into v_base
    from public.crm_stage where org_id = p_org;
  if v_base + v_n > 1000000000 then
    raise exception 'stage_order_overflow: the stage order is out of range; ask Lectual' using errcode = '23514';
  end if;
  update public.crm_stage s set order_index = (v_base + o.ord)::int
    from pg_catalog.unnest(p_ids) with ordinality as o(id, ord)
   where s.id = o.id and s.org_id = p_org;
  update public.crm_stage s set order_index = ((o.ord - 1) * 10)::int
    from pg_catalog.unnest(p_ids) with ordinality as o(id, ord)
   where s.id = o.id and s.org_id = p_org;
end
$$;

-- lectual.app resolveStage (src/lib/lawmatics/stage-map.ts) over one firm's lead stages, with ambiguity made explicit: candidates
-- in order; each candidate's key, then (when p_aliases) its ALIASES entry in order; the first key matching ONE stage wins; a key
-- matching TWO OR MORE stops the search and answers NULL (today's code would take the first: a guess). p_open_only limits the
-- stages to category open. The alias table is copied verbatim from ALIASES (keys are normalised names).
create or replace function public.crm_stage_backfill_resolve(p_org uuid, p_candidates text[], p_aliases boolean, p_open_only boolean)
returns uuid
language plpgsql
stable
set search_path = ''
as $$
declare
  c_aliases constant jsonb := '{
    "new pnc": ["New PNC", "Potential New Client", "New Inquiry"],
    "pnc": ["New PNC", "Potential New Client", "New Inquiry"],
    "potential new client": ["Potential New Client", "New PNC", "New Inquiry"],
    "new lead": ["Potential New Client", "New PNC", "New Inquiry"],
    "new inquiry": ["New Inquiry", "Potential New Client", "New PNC"],
    "discovery call scheduled": ["Discovery Call", "Consultation Scheduled"],
    "discovery call": ["Discovery Call", "Consultation Scheduled"],
    "consultation scheduled": ["Consultation Scheduled", "Discovery Call"],
    "legal strategy session scheduled": ["Strategy Session", "Consultation Scheduled"],
    "strategy session scheduled": ["Strategy Session", "Consultation Scheduled"],
    "strategy session": ["Strategy Session", "Consultation Scheduled"],
    "pending loe payment": ["Pending LOE + Payment", "LOE & Invoice Sent", "Engagement Letter"],
    "pending loe and payment": ["Pending LOE + Payment", "LOE & Invoice Sent", "Engagement Letter"],
    "loe and invoice sent": ["LOE & Invoice Sent", "Pending LOE + Payment", "Engagement Letter"],
    "engagement letter sent": ["LOE & Invoice Sent", "Pending LOE + Payment", "Engagement Letter"],
    "signed loe deposit received": ["Signed LOE / Deposit Received", "Hired Client", "Active Matter"],
    "undecided": ["Undecided / Questions", "Undecided"],
    "undecided questions": ["Undecided / Questions", "Undecided"],
    "follow up": ["Follow-Up", "Follow Up"],
    "lost lead": ["Lost", "Lost Lead"],
    "lost": ["Lost", "Lost Lead"],
    "nurture": ["Nurture"]
  }';
  v_cand text;
  v_key text;
  v_try text;
  v_tries text[];
  v_n int;
  v_id uuid;
begin
  foreach v_cand in array p_candidates loop
    v_key := public.crm_stage_name_key(v_cand);
    v_tries := array[v_key];
    if p_aliases and c_aliases ? v_key then
      v_tries := v_tries || array(select public.crm_stage_name_key(a)
                                    from pg_catalog.jsonb_array_elements_text(c_aliases -> v_key) with ordinality as t(a, i)
                                   order by i);
    end if;
    foreach v_try in array v_tries loop
      select pg_catalog.count(*), (array_agg(s.id))[1] into v_n, v_id
        from public.crm_stage s
       where s.org_id = p_org and (not p_open_only or s.category = 'open')
         and public.crm_stage_name_key(s.name) = v_try;
      if v_n = 1 then return v_id; end if;
      if v_n > 1 then return null; end if;
    end loop;
  end loop;
  return null;
end
$$;

-- -- 8. Stage functions ----------------------------------------------------------------------------------------------
-- Locking (header): the per-firm advisory lock serializes these functions; only the stage being changed (and on delete its records)
-- is row-locked up front. The part 4 trigger does not judge these functions (they run as the table owner, not `authenticated`).
-- 8a. Lead stages (crm_stage).

create or replace function public.crm_stage_add(p_name text, p_position integer, p_category text default 'open')
returns uuid
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_org uuid := public.crm_stage_require_owner();
  v_name text := public.crm_stage_clean_name(p_name, 80);
  v_ids uuid[];
  v_id uuid;
  v_max int;
begin
  if public.crm_stage_name_key(v_name) = '' then
    raise exception 'stage_bad_name: a stage name needs at least one letter or digit' using errcode = '22023';
  end if;
  if p_category is null or p_category not in ('open', 'won', 'lost', 'nurture') then
    raise exception 'stage_bad_category: a stage is open, won, lost or nurture' using errcode = '22023';
  end if;
  perform pg_catalog.pg_advisory_xact_lock(pg_catalog.hashtextextended('crm_stage:' || v_org::text, 0));
  v_ids := public.crm_stage_ordered_ids(v_org, null);
  if pg_catalog.cardinality(v_ids) >= 200 then
    raise exception 'stage_limit: a firm has at most 200 lead stages' using errcode = '23514';
  end if;
  if p_position is null or p_position < 0 or p_position > pg_catalog.cardinality(v_ids) then
    raise exception 'stage_bad_position: no such place in the stage order' using errcode = '22023';
  end if;
  if exists (select 1 from public.crm_stage s where s.org_id = v_org
             and public.crm_stage_name_key(s.name) = public.crm_stage_name_key(v_name)) then
    raise exception 'stage_name_taken: another stage of this firm already has this name' using errcode = '23505';
  end if;
  select coalesce(max(order_index), 0) into v_max from public.crm_stage where org_id = v_org;
  if v_max >= 1000000000 then
    raise exception 'stage_order_overflow: the stage order is out of range; ask Lectual' using errcode = '23514';
  end if;
  insert into public.crm_stage (org_id, name, order_index, category)
  values (v_org, v_name, v_max + 1, p_category::public.crm_stage_category)
  returning id into v_id;
  perform public.crm_stage_renumber(v_org, v_ids[1:p_position] || v_id || v_ids[p_position + 1:]);
  return v_id;
end
$$;

create or replace function public.crm_stage_set_category(p_stage uuid, p_category text, p_confirm_no_won boolean default false)
returns void
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_org uuid := public.crm_stage_require_owner();
  v_stage public.crm_stage;
begin
  if p_category is null or p_category not in ('open', 'won', 'lost', 'nurture') then
    raise exception 'stage_bad_category: a stage is open, won, lost or nurture' using errcode = '22023';
  end if;
  perform pg_catalog.pg_advisory_xact_lock(pg_catalog.hashtextextended('crm_stage:' || v_org::text, 0));
  select * into v_stage from public.crm_stage where id = p_stage and org_id = v_org for update;
  if not found then
    raise exception 'stage_not_found: no such stage' using errcode = '42501';
  end if;
  if v_stage.category::text = p_category then
    return;
  end if;
  -- Any lead, merged ones included: a lead must never silently become won (the handoff would be skipped).
  perform 1 from public.crm_lead where org_id = v_org and current_stage_id = p_stage for update;
  if found then
    raise exception 'stage_not_empty: move this stage''s leads first' using errcode = '23514';
  end if;
  if v_stage.category = 'open' and not exists (
       select 1 from public.crm_stage where org_id = v_org and category = 'open' and id <> p_stage) then
    raise exception 'stage_last_open: a firm keeps at least one open stage' using errcode = '23514';
  end if;
  if v_stage.category = 'won' and not coalesce(p_confirm_no_won, false) and not exists (
       select 1 from public.crm_stage where org_id = v_org and category = 'won' and id <> p_stage) then
    raise exception 'stage_last_won: with no won stage, hired clients stay where they are; confirm to go ahead' using errcode = '23514';
  end if;
  -- The role trigger refuses a role that cannot sit on the new category (stage_role_category_mismatch).
  update public.crm_stage set category = p_category::public.crm_stage_category where id = p_stage and org_id = v_org;
end
$$;

-- The live ids of a stage must equal the ids the dialog showed (as a set; no duplicates).
create or replace function public.crm_stage_ids_match(p_expected uuid[], p_live uuid[])
returns boolean
language sql
immutable
set search_path = ''
as $$
  select pg_catalog.cardinality(p_expected) = pg_catalog.cardinality(p_live)
     and (select coalesce(array_agg(x order by x), '{}') from (select distinct x from pg_catalog.unnest(p_expected) x) d)
       = (select coalesce(array_agg(x order by x), '{}') from pg_catalog.unnest(p_live) x)
$$;

create or replace function public.crm_stage_delete(p_stage uuid, p_destination uuid, p_expected_ids uuid[],
                                                   p_role_to uuid default null, p_confirm_no_won boolean default false)
returns jsonb
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_org uuid := public.crm_stage_require_owner();
  v_uid uuid := auth.uid();
  v_stage public.crm_stage;
  v_dest public.crm_stage;
  v_live uuid[];
  v_merged uuid[];
  v_rules int;
  v_role_to uuid := null;
  v_role_drop boolean := false;
  v_last_won boolean;
begin
  if p_expected_ids is null or exists (select 1 from pg_catalog.unnest(p_expected_ids) x where x is null) then
    raise exception 'stage_delete_bad_ids: send the ids of the leads the dialog showed (an empty list for an empty stage)' using errcode = '22023';
  end if;
  perform pg_catalog.pg_advisory_xact_lock(pg_catalog.hashtextextended('crm_stage:' || v_org::text, 0));
  select * into v_stage from public.crm_stage where id = p_stage and org_id = v_org for update;
  if not found then
    raise exception 'stage_not_found: no such stage' using errcode = '42501';
  end if;

  -- Lock every lead in the stage, then read who is there. A lead moved out meanwhile is re-checked by the lock and drops out.
  perform 1 from public.crm_lead where org_id = v_org and current_stage_id = p_stage for update;
  select coalesce(array_agg(l.id order by l.id) filter (where l.merged_into_id is null), '{}'),
         coalesce(array_agg(l.id order by l.id) filter (where l.merged_into_id is not null), '{}')
    into v_live, v_merged
    from public.crm_lead l where l.org_id = v_org and l.current_stage_id = p_stage;

  if not public.crm_stage_ids_match(p_expected_ids, v_live) then
    raise exception 'stage_delete_records_changed: the leads in this stage changed since the dialog opened' using errcode = '23514';
  end if;

  v_last_won := v_stage.category = 'won' and not exists (
    select 1 from public.crm_stage where org_id = v_org and category = 'won' and id <> p_stage);

  if v_stage.role is not null and p_role_to is null then
    if v_stage.role = 'new_enquiry'
       or (v_stage.role = 'signed_loe' and not (v_last_won and coalesce(p_confirm_no_won, false))) then
      raise exception 'stage_holds_role: choose which stage takes this stage''s role' using errcode = '23514';
    end if;
    v_role_drop := true;               -- the rules fall back to today's name match
  elsif v_stage.role is not null then
    if p_role_to = p_stage or not exists (select 1 from public.crm_stage where id = p_role_to and org_id = v_org) then
      raise exception 'stage_delete_bad_destination: no such stage' using errcode = '42501';
    end if;
    if exists (select 1 from public.crm_stage where id = p_role_to and org_id = v_org and role is not null) then
      raise exception 'stage_role_taken: that stage already holds a role' using errcode = '23514';
    end if;
    v_role_to := p_role_to;
  end if;

  if v_stage.category = 'open' and not exists (
       select 1 from public.crm_stage where org_id = v_org and category = 'open' and id <> p_stage) then
    raise exception 'stage_last_open: a firm keeps at least one open stage' using errcode = '23514';
  end if;
  if v_last_won and not coalesce(p_confirm_no_won, false) then
    raise exception 'stage_last_won: with no won stage, hired clients stay where they are; confirm to go ahead' using errcode = '23514';
  end if;

  if pg_catalog.cardinality(v_live) + pg_catalog.cardinality(v_merged) > 0 then
    if p_destination is null then
      raise exception 'stage_delete_needs_destination: choose where this stage''s leads go' using errcode = '22023';
    end if;
    if p_destination = p_stage then
      raise exception 'stage_delete_same_stage: the leads cannot move to the stage being deleted' using errcode = '22023';
    end if;
    select * into v_dest from public.crm_stage where id = p_destination and org_id = v_org;
    if not found then
      raise exception 'stage_delete_bad_destination: no such stage' using errcode = '42501';
    end if;
    if v_dest.category = 'won' and v_stage.category <> 'won' then
      raise exception 'stage_delete_won_destination: leads are never moved into a won stage this way' using errcode = '23514';
    end if;
    if v_stage.category = 'won' and v_dest.category <> 'won' then
      raise exception 'stage_delete_won_source: hired clients move only to another won stage' using errcode = '23514';
    end if;

    -- Live leads: the stage and its clock; lane, last touch and everything else untouched (0085's guard keeps lane_set_*).
    update public.crm_lead set current_stage_id = v_dest.id, stage_entered_at = now()
     where org_id = v_org and id = any (v_live);
    insert into public.crm_activity (org_id, lead_id, type, actor_id, actor_type, payload)
    select v_org, l.id, 'stage_changed', v_uid, 'user',
           pg_catalog.jsonb_build_object(
             'from_stage', v_stage.name, 'to_stage', v_dest.name,
             'from_stage_id', v_stage.id, 'to_stage_id', v_dest.id,
             'reason', 'stage deleted', 'stage_deleted', true)
      from pg_catalog.unnest(v_live) as l(id);

    -- Merged leads (MERGED LEADS in the header): current_stage_id only, through the guard's 0119 branch; no timeline row.
    if pg_catalog.cardinality(v_merged) > 0 then
      perform pg_catalog.set_config('lectual.stage_delete', p_stage::text || '>' || v_dest.id::text, true);
      update public.crm_lead set current_stage_id = v_dest.id where org_id = v_org and id = any (v_merged);
      perform pg_catalog.set_config('lectual.stage_delete', '', true);
    end if;
  end if;

  if v_role_to is not null or v_role_drop then
    update public.crm_stage set role = null where id = p_stage and org_id = v_org;
  end if;
  if v_role_to is not null then
    -- The role trigger refuses a target whose category the role does not allow (stage_role_category_mismatch).
    update public.crm_stage set role = v_stage.role where id = v_role_to and org_id = v_org;
  end if;

  select pg_catalog.count(*) into v_rules from public.crm_automation_rule r
   where r.org_id = v_org
     and pg_catalog.strpos(r.trigger_config::text || r.conditions::text || r.actions::text, p_stage::text) > 0;

  delete from public.crm_stage where id = p_stage and org_id = v_org;

  return pg_catalog.jsonb_build_object(
    'deleted', p_stage,
    'destination', v_dest.id,
    'moved', pg_catalog.cardinality(v_live),
    'moved_ids', pg_catalog.to_jsonb(v_live),
    'merged_moved', pg_catalog.cardinality(v_merged),
    'role_moved_to', v_role_to,
    'role_dropped', case when v_role_drop then v_stage.role else null end,
    'rules_naming_stage', v_rules);
end
$$;

-- 8b. Matter stages (crm_matter_stage).

create or replace function public.crm_matter_stage_add(p_label text, p_position integer, p_is_open boolean default true,
                                                       p_waiting_on text default 'firm', p_phase text default null)
returns uuid
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_org uuid := public.crm_stage_require_owner();
  v_label text := public.crm_stage_clean_name(p_label, 200);
  v_ids uuid[];
  v_id uuid;
  v_base text;
  v_code text;
  v_n int := 1;
  v_phase_type text;
  v_max int;
begin
  if public.crm_matter_stage_label_key(v_label) = '' then
    raise exception 'stage_bad_name: a stage name needs at least one letter or digit' using errcode = '22023';
  end if;
  if p_waiting_on is null or not (p_waiting_on = any (pg_catalog.enum_range(null::public.crm_matter_waiting_on)::text[])) then
    raise exception 'matter_stage_bad_waiting_on: a stage waits on the firm, the client, the USPTO or the court' using errcode = '22023';
  end if;
  if p_phase is not null then
    if p_phase not in ('pipeline', 'pre_filing', 'post_filing', 'maintenance', 'inactive') then
      raise exception 'matter_stage_bad_phase: not a docket phase' using errcode = '22023';
    end if;
    select pg_catalog.format_type(a.atttypid, a.atttypmod) into v_phase_type
      from pg_catalog.pg_attribute a
     where a.attrelid = 'public.crm_matter_stage'::regclass and a.attname = 'phase' and not a.attisdropped;
    if v_phase_type is null then
      raise exception 'matter_stage_phase_unavailable: docket phases are not switched on for this database' using errcode = '23514';
    end if;
  end if;
  perform pg_catalog.pg_advisory_xact_lock(pg_catalog.hashtextextended('crm_matter_stage:' || v_org::text, 0));
  v_ids := public.crm_matter_stage_ordered_ids(v_org, null);
  if pg_catalog.cardinality(v_ids) >= 200 then
    raise exception 'stage_limit: a firm has at most 200 matter stages' using errcode = '23514';
  end if;
  if p_position is null or p_position < 0 or p_position > pg_catalog.cardinality(v_ids) then
    raise exception 'stage_bad_position: no such place in the stage order' using errcode = '22023';
  end if;
  if exists (select 1 from public.crm_matter_stage s where s.org_id = v_org
             and public.crm_matter_stage_label_key(s.label) = public.crm_matter_stage_label_key(v_label)) then
    raise exception 'stage_name_taken: another stage of this firm already has this name' using errcode = '23505';
  end if;

  -- The code: never changes after this (see header).
  v_base := pg_catalog.upper(pg_catalog.left(pg_catalog.regexp_replace(
              pg_catalog.regexp_replace(v_label, ('^\s*\d+[A-Za-z]?(\s*[.' || pg_catalog.chr(183) || ':)' || pg_catalog.chr(8211) || '-]\s*|\s+)'), ''), '[^A-Za-z0-9]+', '', 'g'), 12));
  if v_base = '' then
    v_base := 'STAGE';
  elsif v_base ~ '^[0-9]' then
    v_base := 'S' || pg_catalog.left(v_base, 11);
  end if;
  v_code := v_base;
  while exists (select 1 from public.crm_matter_stage where org_id = v_org and code = v_code) loop
    v_n := v_n + 1;
    if v_n > 999 then
      raise exception 'stage_name_taken: too many stages share this name' using errcode = '23505';
    end if;
    v_code := v_base || '-' || v_n::text;
  end loop;

  select coalesce(max(order_index), 0) into v_max from public.crm_matter_stage where org_id = v_org;
  if v_max >= 1000000000 then
    raise exception 'stage_order_overflow: the stage order is out of range; ask Lectual' using errcode = '23514';
  end if;
  insert into public.crm_matter_stage (org_id, code, label, order_index, is_open, waiting_on)
  values (v_org, v_code, v_label, v_max + 1,
          coalesce(p_is_open, true), p_waiting_on::public.crm_matter_waiting_on)
  returning id into v_id;
  if p_phase is not null then
    execute pg_catalog.format('update public.crm_matter_stage set phase = $1::%s where id = $2', v_phase_type) using p_phase, v_id;
  end if;
  perform public.crm_matter_stage_renumber(v_org, v_ids[1:p_position] || v_id || v_ids[p_position + 1:]);
  return v_id;
end
$$;

create or replace function public.crm_matter_stage_delete(p_stage uuid, p_destination uuid, p_expected_ids uuid[],
                                                          p_role_to uuid default null, p_confirm_open_change boolean default false)
returns jsonb
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_org uuid := public.crm_stage_require_owner();
  v_uid uuid := auth.uid();
  v_stage public.crm_matter_stage;
  v_dest public.crm_matter_stage;
  v_ids uuid[];
  v_role_to uuid := null;
  v_role_drop boolean := false;
begin
  if p_expected_ids is null or exists (select 1 from pg_catalog.unnest(p_expected_ids) x where x is null) then
    raise exception 'stage_delete_bad_ids: send the ids of the matters the dialog showed (an empty list for an empty stage)' using errcode = '22023';
  end if;
  perform pg_catalog.pg_advisory_xact_lock(pg_catalog.hashtextextended('crm_matter_stage:' || v_org::text, 0));
  select * into v_stage from public.crm_matter_stage where id = p_stage and org_id = v_org for update;
  if not found then
    raise exception 'stage_not_found: no such stage' using errcode = '42501';
  end if;

  perform 1 from public.crm_matter where org_id = v_org and stage_id = p_stage for update;
  select coalesce(array_agg(m.id order by m.id), '{}') into v_ids
    from public.crm_matter m where m.org_id = v_org and m.stage_id = p_stage;

  if not public.crm_stage_ids_match(p_expected_ids, v_ids) then
    raise exception 'stage_delete_records_changed: the matters in this stage changed since the dialog opened' using errcode = '23514';
  end if;

  if v_stage.role is not null and p_role_to is null then
    if v_stage.role = 'signed_loe' then
      raise exception 'stage_holds_role: choose which stage takes this stage''s role' using errcode = '23514';
    end if;
    v_role_drop := true;               -- the rules fall back to today's name match
  elsif v_stage.role is not null then
    if p_role_to = p_stage or not exists (select 1 from public.crm_matter_stage where id = p_role_to and org_id = v_org) then
      raise exception 'stage_delete_bad_destination: no such stage' using errcode = '42501';
    end if;
    if exists (select 1 from public.crm_matter_stage where id = p_role_to and org_id = v_org and role is not null) then
      raise exception 'stage_role_taken: that stage already holds a role' using errcode = '23514';
    end if;
    v_role_to := p_role_to;
  end if;

  if pg_catalog.cardinality(v_ids) > 0 then
    if p_destination is null then
      raise exception 'stage_delete_needs_destination: choose where this stage''s matters go' using errcode = '22023';
    end if;
    if p_destination = p_stage then
      raise exception 'stage_delete_same_stage: the matters cannot move to the stage being deleted' using errcode = '22023';
    end if;
    select * into v_dest from public.crm_matter_stage where id = p_destination and org_id = v_org;
    if not found then
      raise exception 'stage_delete_bad_destination: no such stage' using errcode = '42501';
    end if;
    if v_dest.is_open <> v_stage.is_open and not coalesce(p_confirm_open_change, false) then
      raise exception 'stage_delete_open_mismatch: the destination would reopen or close these matters; confirm to go ahead' using errcode = '23514';
    end if;
    update public.crm_matter set stage_id = v_dest.id, stage_entered_at = now(), updated_at = now()
     where org_id = v_org and id = any (v_ids);
    insert into public.crm_activity (org_id, matter_id, type, actor_id, actor_type, payload)
    select v_org, m.id, 'stage_changed', v_uid, 'user',
           pg_catalog.jsonb_build_object(
             'from_code', v_stage.code, 'from_label', v_stage.label,
             'to_code', v_dest.code, 'to_label', v_dest.label,
             'from_stage_id', v_stage.id, 'to_stage_id', v_dest.id,
             'reason', 'stage deleted', 'stage_deleted', true)
      from pg_catalog.unnest(v_ids) as m(id);
  end if;

  if v_role_to is not null or v_role_drop then
    update public.crm_matter_stage set role = null, updated_at = now() where id = p_stage and org_id = v_org;
  end if;
  if v_role_to is not null then
    -- The role trigger refuses a target that breaks the open / closed rule (stage_role_category_mismatch).
    update public.crm_matter_stage set role = v_stage.role, updated_at = now() where id = v_role_to and org_id = v_org;
  end if;

  -- 0042's ON DELETE RESTRICT stays the backstop: a matter that slipped in would make this fail, never orphan.
  delete from public.crm_matter_stage where id = p_stage and org_id = v_org;

  return pg_catalog.jsonb_build_object(
    'deleted', p_stage,
    'destination', v_dest.id,
    'moved', pg_catalog.cardinality(v_ids),
    'moved_ids', pg_catalog.to_jsonb(v_ids),
    'role_moved_to', v_role_to,
    'role_dropped', case when v_role_drop then v_stage.role else null end);
end
$$;

-- -- 9. The role back-fill -------------------------------------------------------------------------------------------
-- One firm at a time. Writes a role only where the role is free in the firm AND the stage holds none (never overwrites what
-- Lectual set). p_dry_run = true writes nothing and returns what it would write. Service role only (Lectual runs it for a new firm).
create or replace function public.crm_stage_roles_backfill(p_org uuid, p_dry_run boolean default false)
returns jsonb
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_pick jsonb := '{}';          -- role -> stage id (lead)
  v_mpick jsonb := '{}';         -- role -> stage id (matter)
  v_ne_name uuid; v_ne_first uuid; v_ne_c uuid;
  v_fu uuid; v_fu_n int; v_fu_r uuid;
  v_cs uuid; v_ch_sk uuid; v_ch_r uuid;
  v_ps_sk uuid; v_ps_r uuid;
  v_pay_sk uuid; v_won_named uuid; v_won_low uuid;
  v_cand text; v_n int; v_id uuid; v_ambiguous boolean := false;
  v_role text; v_label text;
  v_written jsonb := '[]';
  v_skipped jsonb := '[]';
begin
  -- new_enquiry: newEnquiryStage (open; names by key, no aliases; a name matching two open stages = null, no fallback) ...
  foreach v_cand in array array['Potential New Client', 'New Lead', 'New Inquiry', 'New Enquiry'] loop
    select pg_catalog.count(*), (array_agg(s.id))[1] into v_n, v_id from public.crm_stage s
     where s.org_id = p_org and s.category = 'open' and public.crm_stage_name_key(s.name) = public.crm_stage_name_key(v_cand);
    if v_n = 1 then v_ne_name := v_id; exit; end if;
    if v_n > 1 then v_ambiguous := true; exit; end if;
  end loop;
  select s.id into v_ne_first from public.crm_stage s where s.org_id = p_org and s.category = 'open'
   order by s.order_index, s.name, s.id limit 1;
  -- ... and Reconcile `contacted`. Same open stage; at least one by name (Reconcile's always is).
  v_ne_c := public.crm_stage_backfill_resolve(p_org, array['Potential New Client', 'New PNC', 'New Inquiry'], true, false);
  if not v_ambiguous and v_ne_c is not null and v_ne_c = coalesce(v_ne_name, v_ne_first) then
    v_pick := v_pick || pg_catalog.jsonb_build_object('new_enquiry', v_ne_c);
  end if;

  -- follow_up: the ONE open ^follow ?up\b stage, and Reconcile `nurture` agrees.
  select pg_catalog.count(*), (array_agg(s.id))[1] into v_fu_n, v_fu from public.crm_stage s
   where s.org_id = p_org and s.category = 'open' and public.crm_stage_name_key(s.name) ~ '^follow ?up( |$)';
  v_fu_r := public.crm_stage_backfill_resolve(p_org, array['Follow-Up', 'Follow Up', 'Nurture'], true, false);
  if v_fu_n = 1 and v_fu_r = v_fu then
    v_pick := v_pick || pg_catalog.jsonb_build_object('follow_up', v_fu);
  end if;

  -- consult_scheduled (one list, three readers).
  v_cs := public.crm_stage_backfill_resolve(p_org,
    array['Consultation Scheduled', 'Consult Scheduled', 'Consult Booked', 'Strategy Session Scheduled', 'Discovery Call Scheduled'],
    true, false);
  if v_cs is not null then v_pick := v_pick || pg_catalog.jsonb_build_object('consult_scheduled', v_cs); end if;

  -- consult_held: the Stage Keeper (with its fallback to the scheduled stage) and Reconcile must agree.
  v_ch_sk := coalesce(public.crm_stage_backfill_resolve(p_org,
    array[('Consult Held ' || pg_catalog.chr(8211) || ' Proposal in Progress'), 'Consult Held', 'Consultation Held', 'Consult Completed'], true, false), v_cs);
  v_ch_r := public.crm_stage_backfill_resolve(p_org,
    array[('Consult Held ' || pg_catalog.chr(8211) || ' Proposal in Progress'), 'Consultation Held', 'Consult Held', 'Consultation Completed', 'Consult Completed',
          'Consultation Complete'], true, false);
  if v_ch_r is not null and v_ch_r = v_ch_sk then
    v_pick := v_pick || pg_catalog.jsonb_build_object('consult_held', v_ch_r);
  end if;

  -- questionnaire_sent (one list).
  v_id := public.crm_stage_backfill_resolve(p_org, array['Questionnaire Sent', 'Intake Questionnaire Sent', 'Questionnaire'], true, false);
  if v_id is not null then v_pick := v_pick || pg_catalog.jsonb_build_object('questionnaire_sent', v_id); end if;

  -- proposal_sent: Stage Keeper post-consult-sent and Reconcile proposal_sent agree.
  v_ps_sk := public.crm_stage_backfill_resolve(p_org,
    array['Proposal Sent', 'Post Consultation Email Sent', 'Post Consult Email Sent', 'Post Consultation Follow Up'], true, false);
  v_ps_r := public.crm_stage_backfill_resolve(p_org,
    array['Proposal Sent', 'Proposal Sent to Client', 'Proposal Sent', 'Post Consultation Email Sent', 'Post Consult Email Sent',
          'Post Consultation Follow Up'], true, false);
  if v_ps_sk is not null and v_ps_sk = v_ps_r then
    v_pick := v_pick || pg_catalog.jsonb_build_object('proposal_sent', v_ps_sk);
  end if;

  -- follow_up_sent, loe_sent, welcome_sent, opinion_letter_sent (one reader or one shared list each).
  v_id := public.crm_stage_backfill_resolve(p_org, array['Follow-Up Sent', 'Follow Up Sent', 'Post Consultation Follow Up'], true, false);
  if v_id is not null then v_pick := v_pick || pg_catalog.jsonb_build_object('follow_up_sent', v_id); end if;
  v_id := public.crm_stage_backfill_resolve(p_org, array['LOE & Invoice Sent', 'Pending LOE + Payment', 'Engagement Letter Sent'], true, false);
  if v_id is not null then v_pick := v_pick || pg_catalog.jsonb_build_object('loe_sent', v_id); end if;
  v_id := public.crm_stage_backfill_resolve(p_org, array['Welcome Email Sent', 'Welcome Sent'], true, false);
  if v_id is not null then v_pick := v_pick || pg_catalog.jsonb_build_object('welcome_sent', v_id); end if;
  v_id := public.crm_stage_backfill_resolve(p_org, array['Opinion Letter Sent', 'Search Opinion Sent'], true, false);
  if v_id is not null then v_pick := v_pick || pg_catalog.jsonb_build_object('opinion_letter_sent', v_id); end if;

  -- signed_loe: Stage Keeper payment-received and the hired sync's wonTargetStage agree, on a won stage.
  v_pay_sk := public.crm_stage_backfill_resolve(p_org, array['Signed LOE / Deposit Received', 'Deposit Received'], true, false);
  select s.id into v_won_named from public.crm_stage s
   where s.org_id = p_org and s.category = 'won' and s.name ~* 'signed loe|deposit received'
   order by s.order_index, s.name, s.id limit 1;
  select s.id into v_won_low from public.crm_stage s where s.org_id = p_org and s.category = 'won'
   order by s.order_index, s.name, s.id limit 1;
  if v_pay_sk is not null and v_pay_sk = coalesce(v_won_named, v_won_low) then
    v_pick := v_pick || pg_catalog.jsonb_build_object('signed_loe', v_pay_sk);
  end if;

  -- lost.
  v_id := public.crm_stage_backfill_resolve(p_org, array['Lost', 'Lost Lead'], true, false);
  if v_id is not null then v_pick := v_pick || pg_catalog.jsonb_build_object('lost', v_id); end if;

  -- Matter stages: one stage per label rule, or nothing.
  select pg_catalog.count(*), (array_agg(s.id))[1] into v_n, v_id from public.crm_matter_stage s
   where s.org_id = p_org and s.label = 'Signed LOE / Deposit Received';
  if v_n = 1 then v_mpick := v_mpick || pg_catalog.jsonb_build_object('signed_loe', v_id); end if;
  foreach v_role in array array['application_filed', 'oa_issued', 'awaiting_registration', 'publication', 'registered', 'abandoned'] loop
    v_label := case v_role
      when 'application_filed' then 'Application Filed'
      when 'oa_issued' then 'OA Issued'
      when 'awaiting_registration' then 'Awaiting Trademark Registration'
      when 'publication' then 'Publication for Opposition'
      when 'registered' then 'Registered'
      when 'abandoned' then 'Abandoned' end;
    select pg_catalog.count(*), (array_agg(s.id))[1] into v_n, v_id from public.crm_matter_stage s
     where s.org_id = p_org and public.crm_matter_stage_label_key(s.label) = public.crm_matter_stage_label_key(v_label);
    if v_n = 1 then v_mpick := v_mpick || pg_catalog.jsonb_build_object(v_role, v_id); end if;
  end loop;

  -- One stage, one role: a stage picked by two roles gets neither. Then the category rule, then "never overwrite".
  for v_role, v_id in select k, (v #>> '{}')::uuid from pg_catalog.jsonb_each(v_pick) as e(k, v) loop
    if (select pg_catalog.count(*) from pg_catalog.jsonb_each(v_pick) e2(k, v) where (e2.v #>> '{}')::uuid = v_id) > 1 then
      v_skipped := v_skipped || pg_catalog.jsonb_build_object('table', 'crm_stage', 'role', v_role, 'why', 'stage picked by two roles');
    elsif not exists (select 1 from public.crm_stage s where s.id = v_id and (
              (v_role in ('new_enquiry', 'follow_up') and s.category = 'open')
           or (v_role = 'signed_loe' and s.category = 'won')
           or (v_role = 'lost' and s.category = 'lost')
           or v_role not in ('new_enquiry', 'follow_up', 'signed_loe', 'lost'))) then
      v_skipped := v_skipped || pg_catalog.jsonb_build_object('table', 'crm_stage', 'role', v_role, 'why', 'category');
    elsif exists (select 1 from public.crm_stage s where s.org_id = p_org and (s.role = v_role or (s.id = v_id and s.role is not null))) then
      v_skipped := v_skipped || pg_catalog.jsonb_build_object('table', 'crm_stage', 'role', v_role, 'why', 'already set');
    else
      v_written := v_written || pg_catalog.jsonb_build_object('table', 'crm_stage', 'role', v_role, 'stage_id', v_id,
        'name', (select s.name from public.crm_stage s where s.id = v_id));
      if not p_dry_run then
        update public.crm_stage set role = v_role where id = v_id and org_id = p_org and role is null;
      end if;
    end if;
  end loop;
  for v_role, v_id in select k, (v #>> '{}')::uuid from pg_catalog.jsonb_each(v_mpick) as e(k, v) loop
    if (select pg_catalog.count(*) from pg_catalog.jsonb_each(v_mpick) e2(k, v) where (e2.v #>> '{}')::uuid = v_id) > 1 then
      v_skipped := v_skipped || pg_catalog.jsonb_build_object('table', 'crm_matter_stage', 'role', v_role, 'why', 'stage picked by two roles');
    elsif not exists (select 1 from public.crm_matter_stage s where s.id = v_id and (
              (v_role in ('signed_loe', 'application_filed', 'oa_issued', 'awaiting_registration', 'publication') and s.is_open)
           or (v_role in ('registered', 'abandoned') and not s.is_open))) then
      v_skipped := v_skipped || pg_catalog.jsonb_build_object('table', 'crm_matter_stage', 'role', v_role, 'why', 'open / closed');
    elsif exists (select 1 from public.crm_matter_stage s where s.org_id = p_org and (s.role = v_role or (s.id = v_id and s.role is not null))) then
      v_skipped := v_skipped || pg_catalog.jsonb_build_object('table', 'crm_matter_stage', 'role', v_role, 'why', 'already set');
    else
      v_written := v_written || pg_catalog.jsonb_build_object('table', 'crm_matter_stage', 'role', v_role, 'stage_id', v_id,
        'name', (select s.label from public.crm_matter_stage s where s.id = v_id));
      if not p_dry_run then
        update public.crm_matter_stage set role = v_role where id = v_id and org_id = p_org and role is null;
      end if;
    end if;
  end loop;

  return pg_catalog.jsonb_build_object('org_id', p_org, 'dry_run', p_dry_run, 'written', v_written, 'skipped', v_skipped);
end
$$;

  end if;

      create policy crm_custom_field_insert_owner_only on public.crm_custom_field

-- -- KNOWN LIMITS ---------------------------------------------------------------------------------------------------
--   * Deadlocks: a person's lead move into the stage being deleted (row lock on the lead, then the FK's KEY SHARE on the stage) and
--     crm_stage_delete (the stage FOR UPDATE, then its leads) can deadlock; Postgres aborts one with 40P01 after deadlock_timeout and
--     the app retries once, then says a fixed sentence. A move that loses to the delete fails with 23503 on the FK (the stage is gone):
--     never an orphan. A move OUT of the stage that commits first makes the ids differ: stage_delete_records_changed.
--   * Until a firm's roles are set (or where its names support none), a reorder still changes the positional fallbacks: the
--     new-enquiry rule's "first open stage" and the hired sync's "lowest-ordered won stage".
--   * Firm brain stage_mapping entries name stages by NAME. A rename of a stage such an entry names makes that rule find nothing
--     (the app's documented "the firm said what it meant" behaviour). The app should say so on rename (build step 4).
--   * Automation rules naming a deleted stage are not edited; the result counts them (rules_naming_stage).
--   * A stage delete does not stop sequences or run stage_changed automation rules in SQL; the app does what it decides for
--     moved_ids (DELETE WITH MOVE).
--   * A stage holding only merged leads can never change category; delete it with a destination instead.
--   * The last won stage can be deleted only while it holds no lead (its leads may only go to another won stage).
--   * An owner's DIRECT write (lectual's old settings) is limited to owners and guarded by the trigger and the FKs, but skips the
--     functions' last-open / last-won checks, renumbering and name uniqueness.
--   * A new firm gets no roles until Lectual runs crm_stage_roles_backfill for it (or provision_org learns to). Every rule falls back
--     to its name match meanwhile, as today.
--   * The layout does not know which built-in keys a view has; the app ignores unknown ones and adds missing ones at the end.
--   * A platform admin inside a firm has no owner row: no layout writes, no stage functions or structural stage writes, no
--     firm-column definitions there.
