# Lectual MVP design

| File | What it is |
|---|---|
| `Matters_Prototype.dc.html` | Source design (uploaded). Matters worklist and board, Quotes & proposals, Queue/Inbox, My Mail, Reports, Calendar, IP.OS, Forms, Agents, the mailbox OAuth modal, the agent drawer. It needs the design tool's runtime (`support.js`, the `Rail`/`Intake Forms` components, `shader-bg.js`, logo assets, `window.RPB_MATTERS`), none of which is in this repo. |
| `Lectual_Other_Pages.html` | The pages the prototype marks "not wired up", in the same tokens and components: **Documents**, **Client portals**, **Campaigns** and **Settings** (Mailboxes with Gmail/Outlook connect for personal and firm mailboxes, Agents with the three MVP agents and a run log, Team & roles, Firm profile, Modules). It's self-contained, so you can open it straight in a browser. Navigate with `#Documents`, `#Client%20portals`, `#Campaigns` or `#Settings`. |

All sample data is fictional. Build plan: `../docs/MVP-PLAN.md`.
